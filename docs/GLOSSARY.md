# Glossary — Okoa Sem

Status: Proposed

- **AcademicEvent**: Confirmed academic event (CAT, exam, lecture, etc.).
- **ExtractedClaim**: AI-proposed structured information pending verification.
- **CommunicationSource**: Record of an ingestion submission.
- **SourceDocument**: Stored file or text artifact.
- **CourseOffering**: A course delivered in a term to a class group.
- **ClassGroup**: Cohort of students.
- **Verification**: Human confirmation of a claim.
- **Provenance**: Source and history of information.
- **Tenant**: Institution-level data boundary.
- **AgentRun**: Record of an agent execution.
- **Unverified**: Not yet confirmed by authorised user.
- **Superseded**: Replaced by newer version.
